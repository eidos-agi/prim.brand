# Intention

The brand prim is a **kit**. One file: who we are, the rules, the marks, the fonts, and the running blocks.

It is its own Prim. Not a profile of OKF. Not a wrapper around OBIF. OBIF is retired.

`identity.json` is the law. Code in `blocks/` is an asset of that law. If they drift, the kit is wrong.

The pack is the file. `brand.eidosagi.com` is a view. npm is a view. Do not make a second store.

Success: an agent who has never seen Eidos loads `packs/eidos`, validates, answers mark / palette / type / voice / which block to use, and pastes `blocks/lede/` into a page that still looks like the house.
