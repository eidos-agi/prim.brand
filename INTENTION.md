# Intention

A brand prim is a **kit**. Identity without running blocks is a PDF. Blocks without identity are a theme.

`prim.obif` remains the identity grammar other orgs can speak. `prim.brand` is the sendable kit: that grammar **plus** logos, fonts, tokens, and HTML/CSS implementations in the same file.

The pack is the file. `brand.eidosagi.com` is a view. npm is a view. Do not make a second store.

Code in the pack is an asset on a `content_block`. `identity.json` says what a Lede is. `blocks/lede/block.html` is that Lede. If they drift, the kit is wrong.

Success: an agent who has never seen Eidos loads `packs/eidos`, validates, answers mark / palette / type / voice / which block to use, and pastes `blocks/lede/` into a page that still looks like the house.
